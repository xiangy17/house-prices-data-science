# House-prices-data-science

## Overview / 项目简介

House-prices-data-science is an end-to-end data analysis project built on public datasets. It covers the full pipeline from data acquisition and cleaning to exploratory analysis, visualization, and insight extraction. The goal is to demonstrate a reproducible workflow for deriving meaningful conclusions from open data.

House-prices-data-science 是一个基于公开数据集的端到端数据分析项目。覆盖从数据采集、清洗到探索性分析、可视化与洞察提取的完整流程。目标是展示一套可复现的公开数据分析工作流。
